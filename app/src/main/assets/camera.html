Camera live view (RTSP)

Old XMEye / Dahua / Hikvision cameras need Internet Explorer's ActiveX for web video, which no phone browser can run. The live stream itself (RTSP) does work — fill in the details and this builds the stream address and tries to play it.

If it does not play here: Android's browser can't decode every camera stream. Copy the address and open it in VLC (Media → Open Network Stream) or the XMEye app — those always work for live view. This page only builds the correct address and tries a quick preview.
